HOOKS EN REACT

¿Qué son los Hooks en React?

Los Hooks son funciones de React que permiten utilizar diferentes funcionalidades dentro de los componentes.

Por ejemplo, permiten crear estados, ejecutar acciones cuando cambia información de un componente o acceder a determinados elementos.

Los Hooks se utilizan principalmente dentro de componentes funcionales.


¿Cuáles son sus características?

- Son funciones proporcionadas por React.
- Sus nombres generalmente comienzan con la palabra "use".
- Se utilizan dentro de componentes funcionales.
- Permiten agregar diferentes comportamientos a los componentes.
- Existen Hooks incluidos en React y también es posible crear Hooks propios.


¿Para qué sirven?

Los Hooks sirven para utilizar diferentes funciones de React de una manera sencilla.

Por ejemplo, permiten:

- Guardar y modificar estados.
- Ejecutar código cuando ocurre un cambio.
- Compartir información entre componentes.
- Guardar referencias a elementos.
- Organizar y reutilizar lógica.


¿Cuáles son los principales Hooks?

Algunos de los Hooks más utilizados son:

useState:
Permite crear y modificar estados dentro de un componente.

useEffect:
Permite ejecutar una acción cuando se carga un componente o cuando cambia determinada información.

useContext:
Permite compartir información entre diferentes componentes sin tener que enviarla manualmente de uno a otro.

useRef:
Permite guardar una referencia a un elemento o un valor sin provocar una actualización de la pantalla.

useMemo:
Permite guardar el resultado de un cálculo para evitar realizarlo nuevamente de forma innecesaria.

useCallback:
Permite guardar una función para evitar que sea creada nuevamente cuando el componente se actualiza.


EXPLICACIÓN DEL EJEMPLO

En el ejemplo se utilizan dos Hooks: useState y useEffect.

useState se utiliza para crear un contador.

Cada vez que el usuario presiona el botón, el contador aumenta en 1.

useEffect se ejecuta cada vez que cambia el valor del contador.

En este caso, useEffect cambia el título de la pestaña del navegador mostrando el valor actual del contador.

De esta manera se puede observar cómo diferentes Hooks pueden trabajar juntos dentro de un mismo componente.
